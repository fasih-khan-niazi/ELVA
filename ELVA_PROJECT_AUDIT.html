About ELVA

ELVA enables businesses to create, configure, and deploy their own AI chat and voice agents through a guided dashboard. Each customer workspace (tenant) gets isolated data, subscription plans, knowledge bases, analytics, and integrations.

The platform supports inbound phone calls, browser voice testing, website chat embeds, outbound campaigns, CRM-style orders and leads, connector automations (email, Slack, WhatsApp), and platform-level administration.

System architecture

ELVA is a three-tier application: a React frontend, a Node/Express API, and a Python AI service.

Platform capabilities

Multi-tenant workspaces

Isolated tenants with roles (business admin, member, platform admin), invites, and audit logs.

Agent builder

Create chat and voice agents with personas, knowledge bases, catalogs, and connector rules.

Voice agents

Inbound phone, browser test calls, outbound campaigns, call history, and analytics.

Knowledge & RAG

Upload PDFs; chunks stored in Supabase; retrieved at chat and voice runtime.

Commerce & CRM

In-chat orders and leads, catalog management, and workspace reporting.

Subscriptions

Free, Starter, Pro, and Enterprise plans with usage limits enforced per tenant.

Website chat embed

Public chat widget and API for customer websites with origin controls.

Connectors

Automate actions via email templates, Slack, WhatsApp, and scheduled digests.

Running locally

Three terminals are required — one per service:

ServiceCommandPort
AI servicecd ai_service && py -m uvicorn main:app --reload8000
Backendcd backend && npm run dev3000
Frontendcd frontend && npm run dev5173

Copy each .env.example to .env and fill in API keys before starting. The frontend dev server proxies /api requests to the backend automatically.
